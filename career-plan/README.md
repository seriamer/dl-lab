## 新 Grok 会话怎么接上（三选一）

### 方法 1：同一个 Project 开新对话（推荐）

Grok 的 **Project 会保留 `/workspace` 文件**。在本项目里新开一个 chat，第一句粘贴：

见 [`GROK_HANDOFF.md`](GROK_HANDOFF.md)

或更短：

```
先读 /workspace/AGENTS.project.md 和 /workspace/career-plan/ ，按里面的规划继续帮我执行，不要重新规划方向。
```

### 方法 2：把交接提示词贴进任意新对话

打开 [`GROK_HANDOFF.md`](GROK_HANDOFF.md)，全文复制发送。那份已经浓缩了画像、结论和当前任务。

### 方法 3：下载 markdown 当附件

本目录所有 `.md` 也在预览站可下载。换设备时把整个 `career-plan/` 文件夹保存一份。

**做不到的事：** 没法把「这个 chat 的全部气泡」一键克隆到另一个会话。能共享的是 **写进项目里的文件**。所以执行中的新决定（换组、装环境成败、刷了多少题）要回来改这些文档，或在新对话里补一句近况。
