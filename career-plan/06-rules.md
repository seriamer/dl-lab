# 06 · 每周规则与资源

## 时间盒

| 块 | 时长 | 规则 |
|---|---|---|
| 组里安全课题 | **12–15h** | 白天连续做完；顶格 15h；不加戏 |
| 可翘的课 | — | 能翘则翘，把上午留给代码 |
| 不能挂的课 | — | 考试课、记平时分、学位英语/政治 |
| 自学 | 周均约 **30h** | 工作日晚 3.5–4h；周末 8–10h；国庆 7–8h/天 |

同时只开 3 条自学线：

1. 深度学习 / 具身项目  
2. LeetCode  
3. Linux / ROS（**10/05 才开始**，阶段 A 前两周没有第 3 条）

周日晚 30 分钟对照阶段表打勾。没完成就压缩娱乐，不新开坑。

## 组里安全课题

- 问：这段活能否写成简历上的系统 / 数据 / 模型 / 工程？能 → 留代码和结果  
- 纯网安论文、漏洞、密码 → 做完上交，晚上切回自己的线  
- 这学期不跟导师开第二战场  
- 研一下若仍是无关活且 >15h，再评估换活或换组  
- 不要为组里无偿加班耽误阶段 A 国庆周  

## 每日上课日模板

```
08:00–17:00  课 / 组会 / 课题
19:30–21:00  深度学习（90min，最重要）
21:10–22:10  LeetCode 1–2 题
22:10–22:40  可选笔记；阶段 A 不要拿来装 ROS
周日晚上     git push + 打勾
```

崩了就降级：每天 1 题 + 本周项目至少一次有效提交。

## 刷题

- 语言：Python（C++ 寒假有余力再补）  
- 阶段 A：20 题，数组 / 哈希 / 双指针 / 链表  
- 12/20：约 80  
- 寒假结束：约 110–130，Hot 100 过大半  
- 目的：2027 年 3 月实习笔试过线，不是竞赛

## 简历用语（从现在就按这个写项目）

写结果：数据、指标、你做了哪一段、别人怎么复现。  
不写：负责参与学习、熟悉掌握各种框架、深入研究。

阶段 B 视觉作业示例：

> 基于 ViT/CLIP 微调图像检索（或分类），提供 FastAPI 推理接口；说明数据规模、延迟、失败案例。

不要写成「计算机视觉算法工程师实习项目」。
