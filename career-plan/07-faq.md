# 07 · 已讨论过的问题（避免新会话再辩一轮）

## 为什么还要碰图像？网上都说 CV 没前景

「CV 死了」通常指：

1. 大厂内容理解 / 人脸 / 推荐配图算法岗编制收缩，没顶会很难进核心  
2. 工厂调 HALCON / 海康应用视觉：门槛低、薪资一般  
3. 只会 finetune YOLO、没有系统能力，不好找「算法岗」

**没死的是：** 机器人仍靠相机。具身 JD 很少叫「CV 算法」，但几乎都写视觉编码器、ViT、多模态。VLA 的 V 就是 Vision。

因此：

- **求职标签不是** CV 算法工程师  
- **能力要有：** 图怎么进网络、CNN/ViT 差别、训练为何不收敛、怎么看错样本  

原方案里「项目 1 = 完整工业检测」容易理解成去投 CV 岗，**已取消**。改成：阶段 A 几乎不碰检测；阶段 B 用 1–2 周做一个视觉 + FastAPI 小服务，立刻转 LeRobot。

顺序：

```
会训一个（可以是分类/小 ViT）模型
  → Transformer 写顺（你卡在 attention，这才是缺口）
    → 图像序列 → 动作（ACT / 具身）
```

## 那为什么不直接上 VLA / LLM / 纯后端？

VLA 吃的是相机帧 → Transformer → 动作。没写过训练循环、没处理过图像 batch，LeRobot 会卡在数据、归一化、loss、显存上，看起来像学具身，其实在补课。

后端要保留：具身公司大量缺数据管线、训练脚本、推理服务、ROS 节点。FastAPI 包模型比再刷一个 mAP 更像你能干活。

纯 LLM 实习 2024–25 多，但和你的具身兴趣、以及「机器人要眼睛」匹配更差；当作辅线投递可以，不当主科学。

## 为什么不先把网安补上？专业毕竟是网安

用户已明确不考虑网安方向。学位当背景，技能当门票。网安岗位只在秋招算法全挂时作国企/安全厂商保险。证书、CTF、密码学竞赛这学期不碰。

课设若能选：往视觉、异常检测、模型安全靠，方便简历写成系统/AI，而不是纯网安。

## 没实验室 GPU 怎么办？

已经有了：工位 **5060 Ti 8GB**。不是没卡，是没集群。阶段 A–D 够用。见 [05-hardware.md](05-hardware.md)。

## 组里 12–15h 会不会把计划拖死？

时长可接受，方向无关。当必修作业卡死 15h。见 [06-rules.md](06-rules.md)。不要现在跟导师闹翻。

## 课都能翘，要不要每天学 10 小时？

不必。周均 30h 自学 + 组里 15h 已经很满。翘课省下的时间用来 **写代码**，不是用来多开公开课。挂科成本高于少训一周。

## 要不要发论文？

就业导向：能跑的 demo + 实习 > 二区水文。论文能加分但不作为阶段 A–D 目标。不要为组里安全水文牺牲国庆和寒假。

## 要不要买机械臂 / 5060 Ti 16GB？

不买。真机放到实验室或实习。8GB 不够再租云，先别升级硬件。

## 华科机械学院进得去吗？

进核心组难。帮着标数据、跑仿真、写 ROS 包更现实。阶段 A 结束后再去敲门，带着「我会 PyTorch、能在 50Ti 上训」比空兴趣有用。

## 新会话最常见的错误

- 重新建议转网安或考公  
- 重新布置工业 YOLO 三个月项目  
- 让用户马上装 Isaac Sim  
- 忽略 8GB 限制去训 7B VLA  
- 把组里 15h 改成「辞职式摆烂」或「全力给导师」两个极端
