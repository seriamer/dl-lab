## 阶段 B：2026-10-08 → 12-20

### 10/08–10/19 · 小视觉作业（约两周，不是求职向检测岗）

目的：图像 tensor、预训练、失败样本、**用后端把模型接到 HTTP**。

二选一，选了别换：

- **优先：** CLIP 图文检索，或 HuggingFace 上 ViT 小分类微调  
- **或：** YOLO **只**跑官方预训练 + 自己拍约 20 张图推理，不要做完整工业数据集  

然后 FastAPI 包推理，本地能 `curl` 出结果。

交付：

- GitHub 公开，clone 能跑  
- README：任务、怎么启动、一张效果图、API 示例  
- 简历用语：「视觉模型推理服务」，禁止「CV 算法研究 / 负责深度学习算法」这种空话  

### 10/20–11/30 · 接到具身工具链

- Linux 里装 [LeRobot](https://github.com/huggingface/lerobot)；先把数据格式和训练命令跑通  
- 真训练在 50Ti 上：`batch_size=4 或 8` + fp16  
- ROS2（Humble 或 Jazzy，跟 Ubuntu 版本）：turtlesim + 一个 pub/sub。先搞懂 node / topic / tf  
- 把 ACT（Action Chunking Transformer）和自己写过的 attention 对上  
- LeetCode 累计约 **65**（补二叉树、栈）  
- 有余力：加 2–3 个华科机械 / AIA / 视觉师兄，问组里要不要跑仿真的人  

中文可参考 [LeRobotTutorial-CN](https://github.com/CSCSX/LeRobotTutorial-CN)，以官方仓库为准。
