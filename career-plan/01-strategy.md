# 01 · 求职定位与战略

## 一句话

用大约 18 个月变成 **能进具身团队干活的工程师**，用第 2 个暑假把实习换成校招 offer。  
不是转行当科学家，也不是把网安学位读成网安工作。

## 岗位分层（2026 市场口径）

具身在招、溢价在，但缺的是「能让机器人在仿真/真机上动起来的人」，不是「听过 attention 的研一」。

| 岗位 | 2028 暑假前你够不够格 | 2029 届硕士一线大致年薪 | 策略 |
|---|---|---|---|
| 具身基础模型 / 世界模型研究员 | 很难 | 高但不稳、偏博士 | 不作为主目标 |
| VLA / 操作策略 **应用**算法 | 有项目 + 一段实习才有机会 | 约 35–55 万 | 中期主攻 |
| 感知 / 仿真 / 数据 / 部署工程 | 最贴你的补齐路径 | 约 30–45 万 | **主攻且更好进** |
| 机器人软件（ROS / C++ / 服务） | 后端可迁移 | 约 28–42 万 | 强辅线 |
| 多模态 / 大厂视觉应用 | 实习池最大 | 约 35–50 万 | 保实习、保秋招 |
| 网安研发 | 专业对口但你不做 | 约 25–40 万 | 秋招全挂才捡，不投入时间 |

简历标签写：**具身方向算法工程 / 机器人软件**。  
不要写：计算机视觉算法工程师、网络安全研究员。

## 技能优先级（就业向，已砍学术）

### P0 — 阶段 A 必须（→ 2026-10-07）

1. Python 面试：LeetCode 热题，先 20，寒假约 110  
2. PyTorch 闭环：数据 → forward → loss → backward → step → 验证  
3. 把 attention 后面补完：MHA、FFN、残差、LN，自己写出 EncoderBlock  
4. Git + 工位 Linux 最小环境（国庆有一天装 WSL2/Ubuntu）

### P1 — 研一上后半 + 寒假

5. 很短的视觉作业：会读图、会微调小模型、会看错样本（**不是**工业检测流水线）  
6. 后端接上：FastAPI 包一层推理  
7. 机器人最小集：坐标直觉、ROS2 turtlesim、node/topic  
8. LeRobot + **ACT** 仿真训通、录 eval 视频  

### P2 — 有余力（研二）

9. PPO/SAC 或 Isaac 里一个小操作/运动任务  
10. 真机（实验室或实习提供，自己先不买臂）  
11. ONNX / TensorRT 边端  

### 明确暂缓

密码学深造、CTF、NISP、从零世界模型、Sutton 课本通读、Isaac 数千并行环境、7B VLA 全参训练（8GB 也不够）。

## 三年执行逻辑

```
研一上：能训、懂 Transformer、有小仓库
研一下～暑假：出门实习（CV/多模态/机器人软件/具身数据都可以）
研二上：把一条线做深（ACT/仿真/数据管线）
研二暑假：可转正实习
研二末秋招：用两段实习 + demo 视频谈薪
研三：论文尽量贴近实习，不新开方向
```

**切换开关（防止一把梭）：**

- 2027 暑假前项目能跑、笔试能过 → 继续具身  
- 2027 暑假只收到 CV/多模态实习 → **去**，经历可迁移  
- 2028 年 3 月仍没有相关实习或硬项目 → 主投多模态应用 / 机器人软件 / AI 工程，具身改加分项  

## 资本

- 技能履历优先于奖学金等级  
- 带薪实习：一线 AI/机器人常见日薪，两段 3–4 个月往往比竞赛奖实际  
- 研一不创业、少接外包  
- 组里无偿网安加班，换不来 2027 暑假门票就减时
